# VQCC: first complete circuit verification

The quadratic four-region candidate passed full native verification and reduced
Q*C by **16.7865%** relative to the supplied Newton-Raphson reference.
The improvement factor is **1.201728766x**. These are measured results, not estimates.

| Metric | Reference | Candidate |
|---|---:|---:|
| Native verification | PASS | PASS |
| Inputs | 3,133,452 | 3,133,452 |
| Shots per input | 64 | 64 |
| Verified shots | 200,540,928 | 200,540,928 |
| Logical qubits Q | 260 | 241 |
| Toffoli gates | 7,735 | 6,908 |
| Toffoli-equivalent C, including rotation synthesis | 7,987.593207 | 7,170.769907 |
| Task cost Q*C, lower is better | 2,076,774.233715 | 1,728,155.547512 |
| Worst phase error / allowed tolerance | 0.476912 | 0.884574 |
| Verifier wall time on this runner, seconds | 1,184.67 | 1,104.08 |

The candidate uses 7.31% fewer qubits and 10.69% fewer Toffoli gates.
Its worst observed phase error consumes 88.46% of the tolerance, leaving an
11.54% local tolerance margin. The cost already includes the synthesis penalty
associated with that smaller margin.

Both circuits restored x and cleaned their scratch registers in every tested
shot. A no-phase circuit was rejected at x=2 by the negative control.

## What this establishes

This is a valid locally verified conventional optimization of the initial
reference. It does not establish new physics, an advantage of the Resolutive
Optimizer, or competitiveness against the current leaderboard. RO was not used
in this first experiment. No Kaggle submission was made.

The next meaningful experiment is to expose approximation parameters to RO,
compare it with conventional search under the same evaluation budget, and
verify the selected circuit. Before claiming prize prospects, authenticate the
verifier package and compare against current public competitors and all three
competition tasks.
